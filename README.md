## 🚀 Who am I?

Software Engineering student and backend engineer building **production-grade systems** with **Java & Spring Boot**.

**Co-founder & backend lead @ [Agillis](https://www.agillis.app/admin)** — a multi-tenant SaaS scheduling platform for barbershops and salons, **live with real paying customers**. I designed and built the entire backend: JWT auth, tenant isolation, Google Calendar integration and recurring payments via Mercado Pago.

Also proficient in **Python/FastAPI**. My philosophy: *clean architecture and real-world.*
